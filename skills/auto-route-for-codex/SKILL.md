# Auto Route for Codex Public Preview

Run only after a host-selected `$auto-route-for-codex` invocation. Produce a recommendation that follows the bundled versioned contract. Do not read local session files, create or fork tasks, navigate, archive, change configuration, use credentials, or claim live host capability evidence.

This public preview is recommendation-only. A local-enhanced transfer decision is not portable evidence and must be reduced to `stay` when live current-setting, catalog, or host-capability evidence is unavailable.

Use only models declared in `host_models`, role mappings declared in `host_role_models`, and thinking values declared in `host_thinking`. If no concrete supported combination exists, return an unresolved advisory with null tool overrides. Recommend `parallel` only when delegation is authorized and observed independent-workstream evidence satisfies every public profile predicate.
