# Roadmap

## Before beta

- validate installation from a clean public clone;
- expand real-world routing evaluations without collecting private prompts;
- document additional Codex surfaces;
- add stable machine-readable compatibility metadata;
- publish signed or attestable release provenance when the hosting workflow supports it.

## Before stable

- freeze the public input and output contract;
- define deprecation and migration windows;
- demonstrate backward-compatible upgrades;
- complete independent security review of the recommendation boundary.

## Non-goals

- automatic model switching;
- hidden invocation;
- task transfer or archive in the public edition;
- collecting user prompts for analytics;
- claiming universal model rankings.
