# Security policy

## Supported versions

Only the latest tagged public alpha receives security fixes. Older alpha versions may be unsupported.

## Report a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a public Issue containing exploit details, credentials, private prompts, local paths, or task data.

Include:

- affected version and commit;
- impact and realistic threat model;
- minimal reproduction;
- whether the issue can cause transfer, archive, configuration write, disclosure, or recommendation spoofing;
- suggested mitigation, if known.

## Response goals

Maintainers aim to acknowledge a complete report within seven days. Timelines are goals, not service-level guarantees.

## Scope

The public repository is recommendation-only. Reports about private local editions, unrelated Codex host behavior, or third-party forks should be sent to their respective maintainers.
